PasaScope download page (GitHub Pages), built from site/ on main by .github/workflows/pages.yml.

index.html, styles.css, app.js, fonts.css, fonts/ (self-hosted Prompt, Noto Sans Thai and JetBrains Mono, OFL) and assets/ only. The page reads the latest release from the GitHub
API in the browser, so a new release needs no change here. The screenshots show demonstration data,
not a real child. The app itself is released at https://github.com/monai86/pasascope/releases
