From a recording to a signed report จากไฟล์เสียง ถึงรายงานที่ลงนาม

AI drafts the transcript and counts the tokens. The therapist checks every line, confirms every cue, and signs the report. โปรแกรมช่วยร่างคำถอดเสียงและนับคำ นักแก้ไขการพูดเป็นผู้ตรวจทุกบรรทัด ยืนยันทุก cue และลงนามรายงานด้วยตัวเอง

  1. 1

    Record or openอัดเสียงหรือเปิดไฟล์

    Record in the app, import audio or open a .cha file. Whisper drafts a CHAT transcript locally and separates child and adult turns. อัดเสียงในโปรแกรม นำเข้าไฟล์เสียง หรือเปิดไฟล์ .cha ระบบถอดเสียงและแยกผู้พูดบนเครื่อง

  2. 2

    Check and attestตรวจและรับรอง

    Listen line by line with the active line highlighted. Fix words and speakers, add CHAT codes, then attest in your name. ฟังทีละบรรทัดพร้อมไฮไลต์ตามเสียง แก้คำและผู้พูด ใส่รหัส CHAT แล้วกดรับรอง

  3. 3

    Read the findingsดูตัวชี้วัด

    Inspect each measure with plain explanations and review lines flagged for possible echolalia with reasons. ดูค่าตัวชี้วัดพร้อมคำอธิบาย และตรวจบรรทัดที่เข้าข่ายพูดตามพร้อมเหตุผล

  4. 4

    Sign the reportลงนามรายงาน

    Write your clinical interpretation and goals beside a live A4 print preview, then sign and export PDF. เขียนการแปลผลและเป้าหมายคู่กับตัวอย่าง A4 แล้วลงนามส่งออกเป็น PDF

Stays on this computerอยู่ในเครื่องนี้

  • No account, no server.ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ Thai Whisper and speaker models run locally. Internet access is used only to download speech models and check for app updates. โมเดลถอดเสียงและแยกผู้พูดทำงานบนเครื่อง อินเทอร์เน็ตใช้เฉพาะตอนดาวน์โหลดโมเดลและตรวจหาอัปเดต
  • Consent first.ความยินยอมมาก่อน Caregiver consent is recorded before adding any audio. Withdrawing consent prevents future use of the child's records. ต้องบันทึกความยินยอมของผู้ปกครองก่อนเพิ่มไฟล์เสียง หากถอนความยินยอม ข้อมูลของเด็กจะไม่ถูกนำไปใช้อีก
  • Append-only audit trail.บันทึกการแก้ไขที่ลบไม่ได้ Every transcript edit, attestation and report sign-off is logged with timestamps and cannot be silently altered. ทุกการแก้ไข การรับรอง และการลงนามถูกบันทึกใน audit log ที่แก้ไขหรือลบไม่ได้
  • Unencrypted backup files.ไฟล์สำรองไม่ได้เข้ารหัส Store exported backups only on drives or folders restricted to authorised therapists. เก็บไฟล์สำรองข้อมูลไว้เฉพาะในพื้นที่ที่นักบำบัดเข้าถึงได้เท่านั้น

Does not diagnoseไม่ใช่เครื่องมือวินิจฉัย

  • No yes-or-no verdict.ไม่ตัดสินว่าเป็นหรือไม่เป็น PasaScope never predicts or scores whether a child is autistic. Clinical interpretation belongs strictly to the therapist. โปรแกรมไม่ทำนายและไม่ให้คะแนนความเสี่ยงออทิสติก การแปลผลเป็นหน้าที่ของนักแก้ไขการพูดเท่านั้น
  • No Thai clinical norms yet.ยังไม่มีเกณฑ์มาตรฐานเด็กไทย Measures are descriptive and not yet clinically validated on Thai children. Compare the same child across sessions using similar activities. ตัวชี้วัดเป็นค่าเชิงบรรยายและยังไม่มีผลทดสอบทางคลินิกกับเด็กไทย ควรใช้เทียบเด็กคนเดิมข้าม session ในกิจกรรมคล้ายกัน
  • Verify every line.ตรวจกับเสียงจริงทุกครั้ง Automatic speech recognition makes mistakes on young voices. Measures can only be computed after therapist attestation. ระบบถอดเสียงอัตโนมัติอาจผิดพลาดในเสียงเด็ก ตัวชี้วัดจะคำนวณได้ก็ต่อเมื่อนักบำบัดตรวจและรับรองแล้ว

Questionsคำถามที่พบบ่อย

How do I update, and will I lose data?อัปเดตโปรแกรมอย่างไร ข้อมูลจะหายไหม

PasaScope checks once a day, or use Help → Check for updates…. It backs up first, verifies the new build and installs in place. Cases live outside the app bundle, so nothing is lost. โปรแกรมตรวจหารุ่นใหม่วันละครั้ง หรือกด ช่วยเหลือ → ตรวจหาอัปเดต… ระบบจะสำรองข้อมูลก่อน ตรวจความถูกต้องแล้วอัปเดตทับให้ ข้อมูลเคสเก็บแยกจากตัวโปรแกรมจึงไม่หาย

Where is my data stored?ข้อมูลเก็บไว้ที่ไหน

Only on your computer: ~/Library/Application Support/PasaScope on Mac or %APPDATA%\PasaScope on Windows (File → Open data folder). Back up anytime with File → Back up…. บนเครื่องนี้เท่านั้น ที่ ~/Library/Application Support/PasaScope บน Mac หรือ %APPDATA%\PasaScope บน Windows (ไฟล์ → เปิดโฟลเดอร์ข้อมูล) สำรองได้ที่ ไฟล์ → สำรองข้อมูล…

Which computers are supported?ใช้กับเครื่องไหนได้บ้าง

Macs with Apple silicon (M1 or later) running macOS 12+, and 64-bit Windows 10 or 11. Intel Macs are not supported yet. Mac ชิป Apple (M1 ขึ้นไป) macOS 12 ขึ้นไป และ Windows 10 หรือ 11 แบบ 64 บิต ยังไม่รองรับ Mac ชิป Intel

How accurate is the transcription?ถอดเสียงแม่นแค่ไหน

Young children's speech, background noise and overlapping turns cause errors, so every line must be checked before attesting. On an M2 Mac, accurate mode runs around 3× audio length and fast mode around 0.8×. เสียงเด็กเล็ก เสียงรบกวน และการพูดแทรกอาจทำให้ถอดผิดได้ จึงต้องตรวจทุกบรรทัดก่อนรับรอง บน Mac ชิป M2 โหมดแม่นยำใช้เวลาราว 3 เท่าของความยาวเสียง และโหมดเร็วราว 0.8 เท่า
