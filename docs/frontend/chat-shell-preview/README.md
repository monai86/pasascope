# Chat shell preview screenshots

Captured on 2026-10-13 from `feat/chat-shell`, running against the mock API
(in-memory repository) in public mode (public sign-up, open review gates), with
the interface set to Thai.

The cases shown as `PREVIEW-01` and `PREVIEW-02` are de-identified samples
created through the API for these captures, and their transcripts are a handful
of invented utterances. Nothing here is clinical data.

No language model is involved in anything shown: every line the app says comes
from the session's saved state. Text that the API supplies (the case language,
feature and report content on the full pages) appears as the API sends it.

The 1440-wide and 834-wide captures are at 1× pixel density; the 390-wide ones
are at 2× (780×1688 pixels).
