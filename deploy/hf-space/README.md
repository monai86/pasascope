API for PasaScope, a research and education prototype for reviewing child
language samples. It is not a diagnostic tool and has no Thai clinical
validation.

This Space is built from a bundle of the main repository; edit the code there,
not here. Configuration comes from the Space's secrets and variables. See
`docs/PUBLIC_DEPLOYMENT.md` in the main repository.
